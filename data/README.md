# Website content

The page reads its content from the files in this folder. Edit these files to update the content without changing the layout in `index.html`.

- `bio.json` — name, headline, introduction, optional portrait path, contact note, email, and LinkedIn / Google Scholar profile URLs. Replace the sample values in `linkedinUrl` and `googleScholarUrl` with your profile links. Without a profile URL, an icon remains visible but is not clickable. `introduction` can be a string or an array of paragraph strings; each array item appears as its own paragraph. Put the portrait image at the path in `portrait` (currently `assets/portrait.jpg`); it appears beside the introduction on wide screens and below it on mobile. `contactNote` appears below the “Get in touch” heading on `contact.html`, with the email link below it.
- `experience.json` — a `work` array. Each entry uses `period`, `title`, `organization`, and optional `location`.
- `projects.json` — an array of projects with `type`, `title`, `description`, and a `tags` array.
- `publications.bib` — BibTeX entries. The page displays `title`, `author`, `year`, `journal` or `booktitle`, and `abstract` or `abstractNote`; abstracts appear in an expandable disclosure and support inline `^{...}` superscripts and `_{...}` subscripts. Set `order={1}`, `order={2}`, and so on to control display order; higher numbers appear first. Entries without `order` follow after numbered entries by descending year. Author names are shown in first-name–last-name order, with Nicholas Axel Tanujaya bolded. Set `authororder={alphabetical}` to show the `(α)` author-order marker. Entries default to full papers; set `working={true}` to show a “Working paper” label above the title. Add `doi` or `url` for the original paper link; the publication title links to the same original paper. Add `arxivurl={https://arxiv.org/abs/...}` for an optional full-paper link, or use standard `archivePrefix={arXiv}` and `eprint={...}` fields. For conferences, use the `aaai`, `ijcai`, and `icaps` string variables defined at the top of the file, for example `conference=icaps`; add `conferenceedition={36th}` when you want the edition number shown before the full name. The conference line appears below the authors as **ICAPS 2026**: 36th International Conference on Automated Planning and Scheduling.

Because the page fetches these files, preview it through a local web server or a static host rather than opening `index.html` directly as a `file://` URL. From the website folder, run `sh serve.sh` and open [http://localhost:8000/](http://localhost:8000/). Set `PORT=8080` to use a different port.
